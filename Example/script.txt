## Parameters:
- `-v, --vcf`: Your VCF file
- `-r, --reference`: Reference genome FASTA file
- `-c, --chrom`: Chromosome name (e.g., chr1, Chr1, 1)
- `-p, --position`: Variant position
- `-l, --length`: Flanking sequence length (default: 100bp)
- `-o, --output`: Output file (optional, defaults to stdout)
